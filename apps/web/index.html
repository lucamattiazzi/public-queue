04 / BEFORE YOU CONNECT

A few honest answers.

Can Public Queue read my prompts?

With E2E encryption enabled, the relay stores encrypted prompts and results. It still sees account details, job size, timing, status and routing. Verify your device key locally. For protection against an operator changing browser code, use an independently hosted, reviewed frontend. Losing your browser key means losing access to old encrypted results.

Does my computer need to stay on?

Only while processing jobs. The queue can hold a job while your computer is offline, until its deadline. Your computer must be on, with its model server and agent running, to generate an answer.

Does this work with any website builder?

It works where you can run custom JavaScript and HTTPS requests. The frontend needs a small SDK integration and a way for users to supply their own connection. Never embed a private client credential in a public website.

Is this a streaming chat proxy?

Text responses can arrive progressively, with encrypted blocks saved for replay. Fetch adapters connect existing OpenAI SDK and Vercel AI SDK chat frontends. Image inputs, tools and a public OpenAI-compatible proxy endpoint are not supported. Interrupted inference can run again.

Can I host it myself?

Yes. The relay, SDK and agent are MIT licensed. Hosting the service yourself means managing your own TLS, backups, capacity and security updates.
